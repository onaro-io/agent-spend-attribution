# Contributing

Corrections, mapping errors, and field proposals are welcome.

- Open an issue for anything wrong, missing, or ambiguous, especially an upstream attribute name that has drifted.
- Open a pull request against `SPEC.md` for a concrete change. Include the upstream source for any mapping you add or correct.
- General comments: [hello@onaro.io](mailto:hello@onaro.io)

Implementation reports are the most useful contribution. If you have tried to map real agent spend with this schema, what broke is what the next version needs to fix.
